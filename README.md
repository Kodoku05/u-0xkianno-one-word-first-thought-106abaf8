One word, first thought: **interrobang** — the name of the ‽ mark, a question fused with an exclamation. A program that writes that single word to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty, where an AI judge compares words two at a time on surprise, vividness and wit. Chosen after scanning all 1,480 submitted titles: the field favourites (petrichor, defenestration) are saturated with over a hundred copies each, while interrobang appears in none of them — and it carries its double meaning in its own letters.

## Run it

```sh
node main.ts
```
